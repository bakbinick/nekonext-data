# nekonext-data

NekoNext eklentisinin herkese açık dosyaları. **Burada kod yok.**

- `selectors.json` – Netflix, Prime Video ve Disney+'taki "atla", "sonraki bölüm" ve "hâlâ izliyor musun?" düğmelerinin listesi. Bir site düğmesini değiştirince bu dosya güncellenir, eklentiler ertesi gün kendiliğinden düzelir. Her değişiklikte `version` numarasını 1 artır.
- `privacy.html` – Gizlilik politikası (Chrome Web Store başvurusunda kullanılır).
